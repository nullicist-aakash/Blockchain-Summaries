Chapter 1 Getting Started

1.1 Assumptions from the reader

We want to start with the simple assumption: you know about bitcoin but are not confident with your knowledge. You want to go deep into the technical aspects of bitcoin to get the complete knowledge of how it is working under the hood. You came to the right place. In this book, you will see how the bitcoin data is stored in the blockchain. You will see how it is processed to achieve the magic it claims to achieve.

Another way of thinking is: You are bored with various blockchain tutorials online which only covers the topic from surface but don’t go much into technical details. You are bored with top-down approach available online which don’t go much down into the technology. You want to start with bottom-up approach with some knowledge of what is happening on top level. You want sufficient rigor in the material so that you are absolutely sure about the technology and how things actually work, instead of them working in “thin air” by magic.

1.2 Content Layout

First, we will study the structure of bitcoin transactions. Here, we will explore how the blockchain data is actually stored in the binary image and how to read it from a simple C++ program. We will not go into the cryptography, and just mention the relevant information from cryptography because these things deserve a complete book on their own. We will simply use cryptographic functions as black box.

Then we will go into the topic of bitcoin address and how it is interpreted, generated, managed and used.

So, let’s get started.

1.3 Prerequisites

  • We will use C++ 17 for our code demonstrations, so the knowledge of it is a must. In addition to basic C++ 17 rules, you should know about:
    • Pointers and how to use char* to iterate over memory in byte level chunks.
    • Alignment and padding of structs.
    • Bitwise operators.
    • Stack and heap allocations.
    • Basic STL Container such as vector, map, set, etc.
    • Fixed-width integers.
    • Stream I/O.
    • Little Endian vs Big Endian.
  • Base systems and encodings:
    • Decimal.
    • Hexadecimal.
    • Binary.
    • ASCII.
  • A working internet connection:
    • To download bitcoin transactions to work on them. This is only required once.
